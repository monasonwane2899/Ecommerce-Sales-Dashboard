# Ecommerce Sales Analysis Dashboard | Power BI

## Project Overview

This project focuses on analyzing Ecommerce sales data using Microsoft Power BI. An interactive dashboard was created to track sales performance, profitability, customer trends, product categories, and payment methods.

## Dashboard Preview

![Ecommerce Sales Dashboard](Screenshots/ecommerce_dashboard.png)

## Tools & Technologies Used

* Microsoft Power BI
* Power Query
* DAX
* Data Visualization
* Data Cleaning and Transformation

## Key Performance Indicators (KPIs)

* Total Sales Amount: 438K
* Total Profit: 37K
* Total Quantity Sold: 6K
* Average Order Value: 121K

## Dashboard Features

1. Sales analysis by state.
2. Quantity analysis by product category.
3. Customer-wise sales performance.
4. Quantity analysis by payment mode.
5. Monthly profit analysis.
6. Profit analysis by product sub-category.
7. Interactive quarterly and state filters.

## Key Insights

* Maharashtra recorded the highest sales among the displayed states.
* Clothing contributed the highest quantity share at 63%.
* COD was the most commonly used payment mode at 44%.
* Printers generated the highest profit among the displayed sub-categories.
* November recorded the highest monthly profit in the dashboard.

## Project Files

* Dashboard: Power BI ('Ecommerce_Sales_Dashboard.pbix') file.
* Dataset: Original sales dataset (`ecommerce_Orders.csv`, `ecommerce_Details.csv').
* Screenshot: Dashboard preview ('ecommerce_dashboard.png').

## Purpose

The objective of this project is to develop practical data analytics skills and understand business performance through interactive dashboards and visualizations.
